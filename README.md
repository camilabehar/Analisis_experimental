# 📊 Laboratorio de Análisis Económico y Visualización de Datos

Bienvenida/o a mi repositorio personal. Este espacio está dedicado a la exploración empírica, el análisis cuantitativo y la experimentación con datos. 

El objetivo principal de este repositorio es aplicar la **visualización de datos para una mejor toma de decisiones**, buscando siempre la manera de transformar datos aislados y variables individuales en una perspectiva global, estructurada y fácilmente comprensible.

## 👩‍🎓 Sobre Mí
Soy estudiante del último tramo de la carrera de Economía. Me apasiona entender las dinámicas detrás de los números y aplicar el rigor analítico a problemas reales. Tengo un interés particular en áreas como la economía del comportanmiento, consumo, finanzas públicas, entre otras áreas y utilizo este espacio para llevar los modelos teóricos a la práctica empírica.

## 📁 Estructura del Repositorio
Aquí encontrarás diversos proyectos y experimentos clasificados en las siguientes categorías:

*   **📈 Análisis de Datos Nacionales:** Exploración, limpieza y modelado de indicadores macroeconómicos y series de tiempo provenientes de fuentes oficiales.
*   **📋 Encuestas y Datos Primarios:** Tratamiento y análisis estadístico de datos microeconómicos obtenidos a través de relevamientos y encuestas propias.
*   **📊 Visualización Estratégica:** Gráficos y reportes diseñados específicamente para sintetizar información compleja y extraer conclusiones accionables.

## 🛠️ Herramientas y Tecnologías
*   **Análisis y Limpieza:** Python (Pandas, NumPy), R, Excel.
*   **Visualización:** Matplotlib, Seaborn, Tableau, Power BI.
